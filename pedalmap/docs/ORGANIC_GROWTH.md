## Speech para comunidades (Telegram / WhatsApp / Discord / foros)

Copia y adapta. Tono útil, no spam.

### Versión corta
Hola. Os dejo PedalMap (pedalmap.es), planificador de rutas bici para España: tipo de bici, desnivel, superficie, viento y GPX a Garmin/Wahoo. Hay plan Free. Guías: https://pedalmap.es/blog — si algo falla en vuestra zona, decídmelo.

### Versión media
Buenas. PedalMap es un planificador web (no red social) para preparar la salida: routing carretera/gravel/MTB, desnivel, viento relativo a la ruta y GPX. Free para probar. Tutorial 5 min: https://pedalmap.es/blog/primera-ruta-pedalmap — feedback bienvenido.

### Si un admin es estricto
¿Permitís compartir una herramienta gratuita de planificación de rutas (pedalmap.es)? Es nuestra, española, con GPX y perfiles de bici. Si no encaja en las normas del grupo, lo dejo. Gracias.

### Variante “alternativa Komoot”
Si alguien busca algo más simple en español para planificar (no tanto para coleccionar tracks), estamos con PedalMap: https://pedalmap.es/alternativa-komoot — comparación honesta en el blog.
